# Oyun Çevirici

Oyundaki yazıları ekrandan okuyup Türkçeye çeviren Android uygulaması.

- Yazı tanıma ve çeviri telefonun içinde çalışır (Google ML Kit). İnternet sadece dil paketini ilk indirirken gerekir.
- Desteklenen diller: İngilizce, Japonca, Çince, Korece, Almanca, Fransızca, İspanyolca, İtalyanca, Portekizce → Türkçe

## APK
Her `main` güncellemesinde GitHub Actions APK'yı derler. APK'yı **Releases** bölümünden indir.

## Kullanım
1. Dil paketini indir
2. "Diğer uygulamaların üstünde gösterme" izni ver
3. Başlat → "Tüm ekran"
4. Oyunda mavi butona dokun = çevir, basılı tut = menü (bölge seçimi, otomatik mod)
